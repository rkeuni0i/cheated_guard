# ADR-002: 평균·표준편차 대신 중앙값·MAD·분위수

## 상태
채택 (Accepted)

## 맥락
개인 결제 금액은 정규분포가 아니라 강한 우편향 롱테일(로그정규에 가까움)이다.
median 18,400원인 사용자의 평균은 26,000원, 표준편차는 45,000원쯤 나온다.
`평균+3σ = 161,000원` 이하는 전부 정상으로 통과되고, 과거의 고액 결제 한 건이
표준편차를 부풀려 임계값을 스스로 무력화한다.

## 결정
1. **로그 변환**으로 분포를 대칭에 가깝게 만든다.
2. **MAD(중앙값 절대편차)** 로 극단값 영향을 제거한다. `1.4826 × MAD`는 정규분포에서
   표준편차와 같은 스케일이 된다.
3. 꼬리 판정은 **경험적 분위수(p95/p99)** 로 한다.

구현: `spendguard/detection/statistics.py::axis_amount`,
`spendguard/profiling/builder.py`.

## 포기한 것
계산 단순성. MAD는 중앙값을 먼저 구해야 하는 2-pass 계산이다.

## 결과
분산이 큰 사용자(프리랜서)와 작은 사용자(정기 지출형)에게 자동으로 다른 기준이
적용된다. `axis_amount`에 `MAD_LOG_FLOOR=0.35` 하한을 두어 지출이 지나치게 균일한
사용자가 과민 반응하지 않도록 보호한다.
