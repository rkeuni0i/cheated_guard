# ADR-003: R4 자동정지에 L1 룰 히트를 필수 조건으로

## 상태
채택 (Accepted)

## 맥락
카드 정지는 사용자 권익에 실질적 영향을 주는 자동화된 결정이다. 스코어 90 이상만으로
카드를 막으면, ML(L3)이 오작동했을 때 **설명 불가능한 이유로 결제 수단이 차단**된다.

## 결정
`grade == R4` 자격을 스코어 ≥ 90 **AND** `severity=HIGH` L1 룰 최소 1개 히트 **AND**
콜드스타트 아님 으로 제한한다. 미달 시 R3로 강등한다.
구현: `spendguard/detection/fusion.py::to_grade`.

- 카드 정지의 근거는 항상 사람이 읽을 수 있는 명시적 룰이다.
- ML은 그 판단을 강화할 뿐 단독 근거가 되지 않는다.
- 콜드스타트 사용자는 근거가 될 개인 데이터 자체가 없으므로 자동정지 대상에서 제외한다.

## 포기한 것
ML만으로 잡히는 일부 조합 패턴의 즉시 차단. 이 경우 R3(알림 + 사용자 확인 시 정지)로
처리된다.

## 결과
대표 시나리오(2.3, 312,000원 PC부품)는 R3로 판정되어 자동정지 없이 알림+추가인증만
발생한다. 사용자가 "내가 안 했어요"로 답하면 그때 R4로 승격되어 정지된다.
`scripts/demo.py`로 재현 가능.
